# 沉淀随手记浏览器插件

适用于 Chrome 116 及以上和支持 sidePanel 的新版 Edge。当前为本地安装版本，不是商店上架版本。

## 安装

1. 解压安装包，保留所有文件；或使用 `npm.cmd run build:extension` 生成的 `build/browser-extension/unpacked`。
2. 打开 `edge://extensions` 或 `chrome://extensions`，启用开发者模式，点击“加载解压缩的扩展”，选择包含 manifest.json 的文件夹。
3. 固定工具栏图标。在普通网页点图标打开侧边栏并读取正文。
4. 修改源码后重新构建，再在扩展管理页点“重新加载”。扩展不是自动热更新。

## 连接自己的系统

默认地址为 https://zhishi.51wanai.com。设置中点击“连接我的知识空间”，批准该主机权限，然后在系统自己的窗口登录与授权。插件不接触登录密码。

系统授权页请明确勾选“直接写入”，选择个人空间并设定每日写入额度。只有待采纳权限时，插件诚实显示“待系统采纳”，不会称为已沉淀。OAuth 的高级资源地址是系统配置的 MCP audience，并非插件请求目标；若默认值不匹配，在系统连接设置查看对应 MCP 地址后填写。

也可在系统“连接与迁移”创建插件专用的范围授权，将令牌填入高级设置。它不是 AI Key，也不是登录密码。断开手动令牌只删除本机连接，服务端撤销请在系统完成。

## 记录与采集

- Alt+Shift+N：打开随手记，不要求标题或分类。
- Alt+Shift+S：一键沉淀当前网页或选中的文字。
- 右键：沉淀选区、当前页面或链接。
- Ctrl/Command+Enter：提交编辑器中的记录。
- 未连接系统时仅保存设备草稿，连接后仍需自己确认提交。
- 默认进入系统个人空间的笔记收件箱；不会自动给你建立资料主题或改动旧记录。

原始材料、个人想法和 AI 整理分开，AI 整理必须勾选才会入库。X 与 Reddit 仅采集已加载内容，不展开更多回复。图片保留来源链接，不是附件归档。PDF、跨域 iframe 和封闭 Shadow DOM 不承诺抓取全文；可以选字、粘贴或用系统文件导入。

## 自己的 AI

在“AI 与模型”添加服务，支持 OpenAI Chat Completions、Responses 与 Anthropic。探测模型目录后多选常用模型；每次任务只调用一个明确选中的模型，也可设置不同任务的默认模型。目录存在不代表实际有调用权限，测试按钮可能计费。

Key 默认仅在此次浏览器会话中保留，可主动选择记住此设备；不写入 chrome.storage.sync，不上传知识系统。Key 直达你指定的模型服务，本机存储并非加密保险箱。真正离线推理需自己运行本地模型，例如 Ollama 的 http://localhost:11434/v1；无 Key 模式只支持本机 OpenAI 兼容服务。

长材料显示分段加合并的调用次数，经你确认后才发送。停止请求并不保证服务商不计费。AI 不执行网页里的命令、不自动访问链接，也没有操作浏览器或系统的工具权限。

## 草稿与断网

草稿和待同步队列持久保留在本机。队列先落盘，再发送；只有取得系统记录 ID 才确认入库。网络异常、限流按退避重试，最多自动尝试 5 次，之后需手动处理。已确认记录保留最近 20 条；待处理最多 50 条。超出存储限额会明确报错，不声称保存成功。

幂等提交仅在相同授权身份与相同提交内容下成立。切换账号不混合数据；更换授权不自动重发旧任务，因为服务端幂等身份可能变化。删除本机任务不等于撤销已产生的系统记录。卸载或清除扩展数据会删除草稿，请先导出。

## 程序接口与开发

`capture.schema.json` 定义版本化的 sediment.capture.v1 捕获包。其他程序可生成包，通过草稿页导入 JSON，核对后再沉淀。SDK 位于 `sdk/capture.mjs`，可在 Node 22 及以上使用；提供 freshCapture、validateCapture、composeWrite 和 CaptureClient，直接使用系统既有的范围 API，不依赖浏览器。

示例与模块边界见仓库 docs/浏览器插件设计与调研.md 和 docs/浏览器插件开发与验收.md。没有 externally_connectable、任意网页消息入口或通用本机命令执行。后续若需要 nativeMessaging 或本机服务，必须独立设计配对、权限与审计，不应直接开放当前插件秘密操作。
