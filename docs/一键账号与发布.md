# 一键创建账号密码

## 用户流程

登录页和注册页均提供“一键创建账号密码”。点击后由浏览器 Web Crypto 生成独立的登录账号和强密码，通过已有 `/api/register` 创建个人账号并建立会话，不新增数据库结构或修改后端认证。

创建成功后留在账号保存卡，不直接跳转。用户可以复制账密、下载文本保存卡，或选中只读输入框手动保存。明确勾选“我已妥善保存账号和密码”后进入知识空间。正常邮箱注册、已有账号登录不受影响。

账号格式为 `sd_<96-bit random hex>@account.invalid`，仅是登录标识，不是真实邮箱。密码有独立的 128-bit 随机部分。不能发送邮件或承诺找回能力，界面和保存文件都明确提示丢失账密可能无法找回。

## 安全与失败恢复

- 随机源不可用时失败，不降级到 `Math.random`。
- 账密只保存在当前 React 状态；不自动写入 localStorage、sessionStorage、URL、日志或剪贴板。
- 服务器沿用已有带盐密码哈希和 HttpOnly 会话，不保存明文密码。
- 复制和下载仅由用户点击触发，明确告知剪贴板 / 文件包含明文密码，建议使用密码管理器，不留在共享设备。
- 未确认保存时提供刷新 / 关闭页面提示。浏览器提示不是持久恢复机制，用户仍需自己保存。
- 提交期间阻止重复点击。网络结果不明时保留同一组账密，不自动重试、不生成新账号；用户可重试创建或选择用这组账密登录。
- 注册成功但进入空间失败时保留保存卡，可重新进入，不再次注册。

## 本地验证

```powershell
npx.cmd vitest run
npm.cmd run build
$env:SEDIMENT_CHROMIUM='<Chromium executable>'
node tests/browser_auth.mjs
$env:PYTHONUTF8='1'
python -m unittest discover -s tests -p test_workspace.py -v
```

浏览器脚本启动随机端口后端与临时数据库，只使用合成账号、笔记和随机测试账密。验证注册会话、保存确认、剪贴板、下载、移动端、私有内容隔离、退出后重新登录、手动注册和数据库密码哈希。保存卡截图遮蔽账密，下载文件检查后删除，关闭浏览器并终止测试进程树。产物在被 Git 忽略的 `test-results/auth`。

现有 Python 全量套件在 Windows 可能因创建符号链接缺少权限、默认 GBK 编码、venv 启动器子进程持有 SQLite 文件而失败；这些不是本次前端改动。应分别记录，不把部分通过说成全量通过，不删除断言或修改后端来规避环境问题。

## 发布边界与回滚

本次只部署本地已构建的 `dist` 前端；不上传数据库、用户导入档案、附件、环境文件或整个工作目录。后端源码及生产账号配置保持不变。

通过宝塔停主服务后做冷备，记录账号 / 知识 / 附件数量和附件摘要；保留完整旧 `dist`。保留旧哈希资源以兼容发布前已打开的页面，先部署新哈希资源，最后替换 `index.html`。由宝塔启动同一项目，仅读回健康状态、首页及发布资源摘要，不在服务器运行测试套件或创建测试用户。Cloudflare 只定向清理本域名首页及本次入口资源，不清空整个 zone。

若读回失败，停止主服务，使用发布备份恢复旧 `dist` 后启动并读回。此版本不需要数据库回滚，不用旧冷备覆盖发布后可能产生的新用户内容。
