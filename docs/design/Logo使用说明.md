# 沉淀 · 归点

项目名称继续使用“沉淀”，标志概念名为“归点”。独立方点象征刚捕捉的想法，连续弯折的实体轮廓象征连接与逐层沉淀，负形保留流动路径。方点与主形形成可记忆的两部分结构，不依靠书本、灯泡或脑形来解释产品。

## 文件

- `public/brand/symbol.svg`：深色单色符号，用于浅色背景。
- `public/brand/symbol-inverse.svg`：反白符号，用于深色背景。
- `public/brand/logo.svg`：符号与“沉淀”字标组合。
- `public/brand/app-icon.svg`：带圆角底的应用图标。
- `public/favicon.svg`：网站图标，与应用图标保持一致。
- `src/Brand.tsx`：跟随界面文字颜色的品牌组件。

建议常规符号使用 24–40px，网站小图标使用 16px 以上；符号四周留出至少其宽度的四分之一。不要压扁、旋转、增加阴影或改动内部负形。浅色背景使用深色符号，深色背景使用反白符号。组合字标使用免费开源的思源黑体，保留与产品界面一致的字形。

主题开关固定于视口右上角，使用太阳与月亮表达浅色和深色，当前模式采用实心反差；与 Logo 的单色语言一致。
