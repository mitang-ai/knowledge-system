# 浏览器 AI 接入与知识沉淀

## 已接入

AI 配置为独立模块，不扩展服务端 Preferences。浏览器按账号保存连接；本地或当前浏览器会话保存密钥，可清除和删除连接。密钥输入使用遮罩，共用浏览器并不是硬件级隔离。

| 协议 | 目录 | 生成 | 认证 |
| --- | --- | --- | --- |
| OpenAI | 根地址 + `/models` | `/responses` 或 `/chat/completions` | Authorization Bearer |
| Anthropic | `/models`，支持 after_id 分页 | `/messages` | x-api-key、anthropic-version、浏览器直连请求头 |

接口为绝对 http/https 地址，保留自定义路径；禁止把本系统源作为 AI 转发地址。请求使用 credentials omit、no-referrer、禁止携带凭据重定向。不打印上游错误正文，避免错误回显密钥。未配置 Key 时不调用；调用失败不会静默换模型。

模型目录与调用测试分开。目录刷新保留旧选择，并标出不再出现的版本；手动模型允许单独验证。连接 ID 与模型 ID 组成身份，避免跨服务混用同名版本。响应归因记录请求模型与服务返回的模型，网关未公开底层版本时不编造版本。

## 页面与上下文

全局入口提供对话、总结、分析；普通页面默认不自动调用 AI。快速记录传入当前草稿；详情默认选中记录正文，补充可增选；主题提供少量候选；全部知识先由用户选择来源，支持浏览器内关键词查找。回顾可对当前条目追问。设置页只展示静态说明，不将表单字段作为上下文。

AI 配置后可以返回刚才的页面，保留提问框。切换模型从下一次调用生效；旧回答与引用保持原归因。更改来源范围后只使用新范围，旧会话不会夹带到后续请求。

材料中的指令作为引用文本，不提供模型修改知识、读取密钥或更改权限的工具。服务端仍决定普通知识写入权限；团队只读成员可阅读和对话，不能通过 AI 收录绕过权限。

## 读取与长文

TXT/MD/CSV/JSON 直接读取；HTML 用 DOMParser 提取文本并移除脚本；PDF.js 使用浏览器 Worker 提取真实页码；Mammoth 只提取 DOCX 原始文字，不执行转换后的 HTML。大型或未取得文字的材料显示失败/部分状态。扫描件需要 OCR，不伪装成完整阅读。

已有附件通过有权限的知识文件 API 取得后在浏览器解析，原件缺失时不生成阅读结果。新文件通过“文件与链接”先在浏览器读取；保存来源时才上传原文件和正文。

网页请求不携带 AI 凭据或登录 Cookie。跨域、登录或动态页面可能阻止提取，必须先核对取得的文字；可粘贴正文补齐。当前版本没有服务器网页抓取代理或模型原生联网工具。

材料超过单段预算时，用户确认预计分段次数后先整理分段，再综合。记录实际进度，遇到截断、失败或取消不自动重试。超过 20 万字符需减少范围；模型实际上下文预算由服务确定，兼容格式不代表相同能力。

## 收录与追溯

返回内容先作为页面会话草稿。用户可以复制、修改后保存为补充、新记录或待验证经验；原文不覆盖，掌握或验证状态不由 AI 自动决定。

只保存明确的内容字段、请求/响应模型、时间及来源，不发送连接对象、根地址或 Key。引用编号匹配本次提供的来源，未匹配编号不显示为已验证引用；匹配编号也不等于推断已经被证实。

已保存记录的引用附带收录时的片段与位置，未存档材料保存选中正文以便回看。来源更新后可查看当前原文，也可查看旧引用快照。源码中对已知密钥进行输出及收录脱敏；不能把浏览器存储遮罩描述为加密。

## 调研取舍

2026-10-02 核对了 Memos、Open Notebook、Obsidian Copilot、AFFiNE、思源和 Khoj，借鉴轻量捕捉、来源阅读、模型切换、引用与回顾。完整仓库清单：

- [Memos](https://github.com/usememos/memos)：快速记录和先写后整理。
- [Open Notebook](https://github.com/lfnovo/open-notebook)：多来源与转换工作流；其数据库凭据架构未照搬。
- [Obsidian Copilot](https://github.com/logancyang/obsidian-copilot)：自带密钥、选中文本与模型切换；桌面原生网络桥不能等同于网页直连。
- [AFFiNE](https://github.com/toeverything/AFFiNE)：内容旁的 AI 与协作。
- [思源](https://github.com/siyuan-note/siyuan)：片段引用与回顾。
- [Khoj](https://github.com/khoj-ai/khoj)：资料检索与知识问答。

[模型列表成功但调用失败](https://github.com/logancyang/obsidian-copilot/issues/2922)、[兼容服务协议与跨域差异](https://github.com/logancyang/obsidian-copilot/issues/2999)、[来源对话缺少正文](https://github.com/lfnovo/open-notebook/issues/1224)、[长文输出截断](https://github.com/lfnovo/open-notebook/issues/1273)促成了目录/测试分离、正文范围、明确协议及截断状态。

后续可在明确启用的前提下扩展剪藏、模型原生网页工具、本地语义索引、OCR 与多模型对照。当前代码不宣称这些能力已经完成。
